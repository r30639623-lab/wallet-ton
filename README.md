# Wallet TON

Web wallet TON ala Tonkeeper, berbahasa Indonesia. Satu file HTML, bisa dibuka langsung di browser HP.

## Fitur

- **Import dompet** pakai 24 kata rahasia (seed phrase) — kata-kata hanya diproses di browser kamu sendiri, tidak disimpan dan tidak dikirim ke server mana pun.
- **Pantau alamat saja** — lihat saldo TON + jetton tanpa memasukkan kata rahasia.
- **Dompet demo** — bikin wallet baru untuk coba-coba (devnet).
- **Saldo TON + jetton** dan **riwayat transaksi** dari alamat mana pun.
- **Terima via QR** dan **kirim via deeplink** ke aplikasi Tonkeeper resmi.

## Cara pakai

1. Buka `index.html` di browser HP atau komputer.
2. Pilih: import dompet (24 kata), pantau alamat saja, atau bikin dompet demo.
3. Cek saldo, terima, atau kirim.

## Keamanan

- 24 kata rahasia adalah kunci dompetmu. Jangan pernah dibagikan, difoto, atau dikirim ke chat — siapa pun yang pegang kata itu bisa menguras isi dompetmu.
- Wallet ini adalah web wallet sederhana untuk belajar dan coba-coba. Untuk dana besar, pakai aplikasi wallet resmi yang sudah diaudit (misalnya Tonkeeper).
- File ini BUKAN file APK. APK beneran butuh proyek Android terpisah (misalnya Flutter + GitHub Actions).

## English summary

A simple Indonesian TON web wallet inspired by Tonkeeper: import a wallet with a 24-word seed phrase (processed locally in your browser only, never stored or sent anywhere), watch-only address lookup, demo wallet, TON + jetton balances, transaction history, receive via QR, send via deeplink to the official Tonkeeper app. Single HTML file — open `index.html` in a browser. This is NOT an APK file.
